# 보안 설계

- 관리자는 짧은 수명의 세션과 역할 기반 접근 제어를 사용한다.
- 강사 응답 링크는 128비트 이상의 난수 토큰 원문을 저장하지 않고 해시만 보관한다.
- 토큰은 수신자·요청·만료 시각·요청 버전에 귀속한다.
- 만료·종료·취소·교체된 요청은 제출할 수 없다.
- 응답 API는 idempotency key와 DB 고유 제약으로 중복 제출을 안전하게 처리한다.
- 최종 배정은 트랜잭션과 낙관적 버전 검사를 사용한다.
- 알림 발송은 idempotency key를 가진 아웃박스로 중복을 방지한다.
- 연락처와 기관 담당자 정보는 최소 권한 사용자에게만 노출한다.
- 관리자 변경, 수업료 변경, 배정 변경은 actor·시각·전후 값을 감사 로그로 남긴다.
- 운영 비밀값은 저장소나 클라이언트 번들에 포함하지 않는다.

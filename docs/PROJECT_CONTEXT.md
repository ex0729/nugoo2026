# 프로젝트 맥락

## 제품 한 줄 정의

클래스플로우(가칭)는 소규모 교육업체가 강사에게 역할별 출강 요청을 보내고 응답을 모아 최종 배정하는 운영 플랫폼이다.

## 기준 문서

- 제품 요구사항의 최상위 기준은 루트의 `prd(1).md`다.
- 서비스명 `클래스플로우`는 UI 제작을 위한 가칭이며 제품 요구사항 확정으로 보지 않는다.
- PRD는 사용자 범위, 핵심 흐름, 권한, 비즈니스 규칙, 기능 범위가 바뀔 때만 수정한다.

## 핵심 사용자와 가치

- 최고 관리자: 회원 승인, 권한, 전체 운영 현황 관리
- 운영 관리자: 수업 등록, 모집, 재알림, 최종 배정
- 소속 강사: 모바일 링크에서 역할별 수업료를 확인하고 응답, 확정 일정 확인
- 핵심 가치: 단체 카카오톡과 개별 연락을 한 화면의 구조화된 응답 흐름으로 대체

## 반드시 유지할 규칙

- 수업별 주강사 1명, 보조강사 0~2명, 총 1~3명
- 모집 역할은 주강사, 보조강사, 두 역할 모두
- 한 강사는 같은 수업에서 한 역할로만 최종 배정
- 역할별 가능·조건부 가능·불가능 응답, 조건부 가능 사유 필수
- 주강사 수업료와 보조강사 1인당 수업료를 분리
- 일정 충돌은 경고하되 자동 제외하지 않음
- 최종 배정은 관리자 결정
- 요청·응답·재알림·배정 변경은 이력 보존

## 현재 단계

- Supabase Auth·PostgreSQL·RLS와 Next.js API를 사용하는 기능 구현 단계
- 수업 등록부터 실제 수업 ID 기반 상세·강사 모집·역할별 응답·최종 배정까지 영속 데이터로 연결
- 관리자 홈·주간 일정·알림 이력의 일부 화면에는 아직 목업 표현이 남아 있음
- 카카오 알림톡과 개인별 보안 응답 토큰은 아직 연동하지 않음

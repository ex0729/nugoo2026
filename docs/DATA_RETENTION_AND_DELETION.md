# 데이터 보관·삭제 기준

## 운영 기준

| 데이터 | 기본 보관 | 삭제·비식별 처리 |
| --- | --- | --- |
| 계정 프로필 | 계정 이용 중 | 탈퇴 완료 후 30일 이내 |
| 수업·모집·응답·배정 | 수업 종료 후 3년 | 통계 목적 값만 비식별 보존 가능 |
| 관리자 감사 기록 | 2년 | 만료 월말 일괄 삭제 |
| 내부 알림 | 1년 | 만료 월말 일괄 삭제 |
| 웹 푸시 구독 | 구독 유효 기간 | 404/410 응답, 알림 해제, 탈퇴 시 즉시 삭제 |
| 초대 토큰 | 만료·사용 후 30일 | 토큰 해시는 즉시 무효화, 기록은 30일 후 삭제 |

## 삭제 절차

- 요청 접수 → 본인·권한 확인 → 법정 보존 예외 확인 → 삭제 또는 비식별화 → 감사 기록에 처리 결과 저장
- 연쇄 삭제 전 수업료·분쟁 관련 보존 필요성을 확인합니다.
- 운영 DB 직접 삭제는 최고관리자 승인과 사전 백업이 있어야 합니다.

## 출시 전 확정 항목

- 사업자의 세무·계약 보존 의무에 맞춘 수업·정산 데이터의 정확한 보존기간
- 탈퇴·열람 요청 접수 화면 또는 공식 이메일 처리 SLA
- 월 1회 만료 데이터 삭제 작업의 실행 담당자

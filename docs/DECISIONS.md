# 의사결정 기록

## ADR-001: Cloudflare 호환 React 구조

- 결정: 공식 Sites Vinext 스타터를 유지한다.
- 이유: 프론트엔드와 향후 D1/API를 한 배포 단위로 운영하고 프리뷰 환경을 단순화한다.
- 대안: 별도 Next.js 서버와 PostgreSQL. 복잡한 정산·보고가 커지면 재검토한다.

## ADR-002: 디자인 우선 인터랙티브 프로토타입

- 결정: 첫 단계는 타입이 지정된 목업 데이터와 실제 상호작용으로 화면 흐름을 검증한다.
- 이유: 월 10건 미만 운영 환경에서 데이터 모델을 조기에 고정하기보다 관리자·강사 사용성을 먼저 검증한다.

## ADR-003: 역할별 수업료 스냅샷

- 결정: 수업의 현재 역할별 수업료와 배정 시점의 적용 수업료를 분리한다.
- 이유: 수업료 변경 후에도 과거 요청·응답·배정 이력을 정확히 재현해야 한다.

## ADR-004: 서비스명은 가칭

- 결정: UI에는 `클래스플로우`를 사용하지만 브랜드 확정으로 PRD를 변경하지 않는다.

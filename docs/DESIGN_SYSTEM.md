# 디자인 시스템

## 원칙

- 관리자는 3초 안에 마감 임박과 미응답을 발견한다.
- 강사는 모바일 링크 진입 후 10초 안에 응답할 수 있다.
- 상태는 색상, 아이콘, 텍스트를 함께 사용한다.
- 관리자 화면은 높은 정보 밀도, 강사 화면은 한 번에 하나의 행동에 집중한다.

## 참고 패턴

- Connecteam Scheduling: 일정 충돌을 숨기지 않고 경고로 노출하며 역할·가용성을 함께 판단하는 구조
- Linear: 얇은 경계선, 명확한 상태, 빠른 필터와 상세 패널
- Toss 계열 UX: 쉬운 문장, 큰 모바일 행동 영역, 명확한 완료 피드백
- Material Design: 터치 영역과 상태 피드백, 접근성 기준

참고 링크: https://connecteam.com/employee-scheduling-app/ · https://linear.app/ · https://developers-apps-in-toss.toss.im/design/components · https://m3.material.io/

## 타이포그래피

- 한글 우선 글꼴: Pretendard, SUIT, 시스템 sans-serif
- 화면 제목: 24~30px / 700
- 섹션 제목: 16~18px / 700
- 본문: 14px / 400~600
- 보조 정보: 12~13px

## 컴포넌트 규격

- 버튼 높이: 기본 40px, 모바일 핵심 행동 52px
- 입력 높이: 44px 이상
- 사이드바: 248px
- 관리자 콘텐츠 최대 폭: 1600px
- 상태 배지: 아이콘 + 상태명, 28px 이상
- 테이블 행: 56~68px
- 모바일 하단 행동 영역: safe-area 포함 고정

## 역할·수업료 표시

- 주강사: 블루 배지, `주강사 · 300,000원`
- 보조강사: 민트 배지, `보조강사 · 1인당 150,000원`
- 역할과 금액은 같은 시각 그룹에서 분리하지 않는다.

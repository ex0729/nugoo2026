# 출시 차단 결함 조치 보고 — 2026-08-12

## 해결 완료

- 강사 수업 조회 RLS의 잘못된 `class_id = target.id` 비교를 실제 `classes.id` 비교로 수정
- 응답 테이블 전체 UPDATE 권한을 제거하고 상태·조건·응답시각 컬럼으로 제한
- 마감 이후 및 배정·완료·취소 수업의 응답/모집/재알림을 DB에서 차단
- 수업 생성 idempotency key와 고유 인덱스로 중복 저장 방지
- 최종 배정 행 잠금, 재확정 거부, 기존 배정 덮어쓰기 제거
- 수업 수정·완료·취소 RPC와 감사 기록, 변경/취소 내부 알림 연결
- 선정·미선정 결과 알림, 강사 확정 일정, 배정 확인 시각 연결
- 신규·변경 비밀번호를 12자 이상과 3종 조합으로 강화하고 흔한 문구 차단
- 개인정보 처리방침 초안, 보관·삭제 기준, 백업·복구 절차 작성

## 운영 전 남은 외부 조치

- 현재 Supabase Free 플랜에서는 유출 비밀번호(HIBP) 보호를 켤 수 없음. Pro 전환 후 Auth 설정에서 활성화 필요
- Free 플랜은 자동 일일 복구 보장이 없으므로 외부 논리 백업 자동화용 `DATABASE_URL` 비밀값과 저장소를 운영자가 구성해야 함
- 개인정보 책임자명·주소·전화, 법률 검토, 실제 복구 훈련, 최종 승인 서명 필요

## 배포 메모

- Vercel은 Next.js 빌드를 사용하고, OpenAI Sites는 같은 소스의 `vinext build` 산출물을 저장 버전에 첨부해 배포합니다.
- 두 호스팅 방식의 빌드 산출물을 분리해 Vercel 설정을 변경하지 않고 Sites 배포 호환성을 유지합니다.

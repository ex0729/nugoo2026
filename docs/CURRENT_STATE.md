- 승인된 강사의 자동 대시보드 이동과 수업 요청·확정 일정 홈 화면

- 비밀번호 변경, 로그인 세션 확인, 다른 기기 로그아웃

- Supabase 이메일·비밀번호 인증 및 서버 세션 보호
- 최고관리자 `누구나코딩교육` 부트스트랩 예약과 4단계 역할 기반 권한 제어
- 회원 승인·거절·역할 변경 API 및 관리자 감사 로그
- Supabase RLS와 Vercel 운영 환경변수 연결

- 공식 Sites 기반 React/TypeScript 프로젝트 초기화
- Vercel용 Next.js 빌드와 Sites용 Vinext 빌드 분리
- Vercel 프로젝트 프레임워크를 Next.js로 설정하고 기존 Vite 출력 폴더 재정의 제거
- 프로젝트 맥락, 아키텍처, 도메인, 디자인, 보안, 테스트 문서
- 관리자 홈, 수업 목록·등록, 역할별 응답 현황, 후보 선택
- 주간 일정, 강사 관리, 회원 승인, 알림 이력
- 주강사 1명·보조강사 0~2명과 역할별 수업료 입력
- 강사 모바일 수업 확인, 역할별 수업료 확인, 조건부 응답, 완료 상태
- 수업·배정 후보·강사 검색과 상태 필터
- 재알림 전송 및 최종 배정 완료 피드백
- 조건부 응답 사유 필수 검증
